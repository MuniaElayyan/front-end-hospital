How a shift works
  1. One person presses Create Game and reads out the room code.
  2. Every student opens the join link, types a doctor name and the code.
  3. The host presses START EMERGENCY.
  4. Twelve classified patient files appear. Each doctor claims exactly one — first click wins.
  5. Read the symptoms and the evidence. Write a diagnosis, a cause and a treatment.
  6. Present at the Medical Conference, then the correct answers are revealed and scored.

Built for a classroom. No accounts, no installs for students — just a link.
